## 测试场景 1：超级管理员配置租户

### 测试步骤

1. **登录超级管理员账号**
   - 访问 `http://localhost:5173/login`
   - 输入超级管理员账号密码
   - 点击登录

2. **访问租户列表页面**
   - 点击左侧菜单"租户管理"
   - 验证租户列表正确显示

3. **配置租户功能模块**
   - 找到测试租户，点击"配置"按钮
   - 验证 TenantConfigPanel 弹窗显示
   - 勾选/取消勾选功能模块：
     - [x] 图片管理
     - [x] 页面配置
     - [ ] 多语言支持
     - [x] 联系表单
     - [x] 内容管理
   - 点击"保存"
   - 验证保存成功提示

4. **配置租户资源配额**
   - 在配置面板中修改配额：
     - 图片数量：100 → 200
     - 存储空间：1024 → 2048 MB
     - 内容项数量：50 → 100
   - 点击"保存"
   - 验证保存成功

5. **配置订阅计划**
   - 在配置面板中选择订阅计划：`free` → `pro`
   - 设置订阅过期时间
   - 点击"保存"
   - 验证保存成功

6. **查看租户详情页**
   - 点击租户名称或"详情"按钮
   - 验证显示：
     - 租户基本信息
     - 功能模块状态（与配置一致）
     - 资源配额使用进度条
     - 订阅计划信息

### 预期结果

- [ ] 超级管理员可以成功配置租户功能模块
- [ ] 超级管理员可以成功配置租户资源配额
- [ ] 超级管理员可以成功配置订阅计划
- [ ] 配置变更后租户详情页实时更新

## 测试场景 2：租户配额超限

### 测试步骤

1. **登录租户管理员账号**
   - 访问 `http://localhost:5173/login`
   - 输入租户管理员账号密码
   - 点击登录

2. **查看 Dashboard 配额使用情况**
   - 验证显示资源配额使用进度条
   - 记录当前图片使用量

3. **模拟配额超限场景**
   - 超级管理员将该租户的图片配额设置为当前使用量

4. **验证配额警告**
   - Dashboard 顶部应显示配额警告提示
   - 进度条应显示红色（错误状态）

5. **尝试上传图片**
   - 进入图片管理页面
   - 尝试上传新图片
   - 验证：
     - 配额不足时显示友好错误提示
     - 图片上传失败

### 预期结果

- [ ] Dashboard 正确显示配额使用情况
- [ ] 配额接近上限（90%）时显示警告提示
- [ ] 配额超限（100%）时显示错误提示
- [ ] 配额不足时图片上传被阻止
- [ ] 显示友好的配额超限错误信息

## 测试场景 4：租户隔离验证

### 测试步骤

1. **准备两个租户账号**
   - 租户 A：`tenant_a@example.com`
   - 租户 B：`tenant_b@example.com`

2. **配置不同配额**
   - 超级管理员为租户 A 设置图片配额：100
   - 超级管理员为租户 B 设置图片配额：500

3. **验证租户 A 无法访问租户 B 数据**
   - 登录租户 A 账号
   - 尝试访问租户 B 的 API 端点
   - 验证返回 403 权限错误

4. **验证配额独立计算**
   - 租户 A 上传图片至配额上限
   - 租户 B 应仍可正常上传图片

### 预期结果

- [ ] 租户只能访问自己的配置数据
- [ ] 租户之间配额独立计算
- [ ] 跨租户访问被正确阻止

## 常见问题排查

### 问题 1：配置保存失败

**可能原因**：
- 后端服务未启动
- JWT Token 过期
- 权限不足

**解决方法**：
- 检查后端服务日志
- 重新登录获取新 Token
- 确认使用正确的账号权限

### 问题 2：配额检查不生效

**可能原因**：
- 中间件未正确注册
- 配额服务逻辑错误

**解决方法**：
- 检查 `backend/routes/routes.go` 中的中间件注册
- 查看 `backend/middleware/quota.go` 逻辑

### 问题 3：功能开关不生效

**可能原因**：
- 前端未正确加载功能状态
- 后端中间件未检查功能开关

**解决方法**：
- 检查 `AuthContext.tsx` 中的 `loadFeatures` 调用
- 查看 `backend/middleware/feature.go` 逻辑
