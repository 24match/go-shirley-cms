## 简介

本快速入门指南旨在帮助新开发者快速搭建**医疗设备官网 CMS 系统**的本地开发环境。该系统是一个基于 **Go + Gin + SQLite** 的内容管理系统，支持用户认证、权限管理、图片管理、页面配置等功能。

项目特点：
- **后端**：Go + Gin 框架，轻量高效
- **数据库**：SQLite 内嵌数据库，无需额外配置
- **认证**：JWT Token 认证机制
- **前端**：原生 HTML/CSS/JS，响应式设计

详细功能说明请参考 [README.md](../../../README.md)。

## 系统要求

在开始之前，请确保您的系统满足以下要求：

- **Go 版本**: Go 1.25.0 或更高版本
- **内存**: 至少 2GB RAM
- **磁盘空间**: 至少 500MB 可用空间
- **网络**: 稳定的互联网连接（用于下载依赖）
- **操作系统**: macOS / Linux / Windows

## 项目克隆

首先，您需要克隆项目到本地开发环境：

```bash
git clone https://github.com/24match/go-shirley-cms.git
cd lihui
```

## 环境准备

### 1. 安装 Go 1.25.0

确保您的系统已安装 Go 1.25.0 或更高版本：

```bash
go version
```

如果未安装，请从 [Go 官网](https://go.dev/dl/) 下载并安装。

### 2. 验证 Go 安装

```bash
go version
go env
```

### 3. 安装项目依赖

项目使用 Go Modules 作为依赖管理工具。在项目根目录下执行：

```bash
go mod download
```

这将下载所有必要的依赖包，包括：
- `github.com/gin-gonic/gin` - Web 框架
- `gorm.io/gorm` - ORM 库
- `gorm.io/driver/sqlite` - SQLite 驱动
- `github.com/golang-jwt/jwt/v5` - JWT 认证
- `golang.org/x/crypto` - 加密工具

## 数据库和缓存服务启动

本项目使用 **SQLite** 作为内嵌数据库，无需单独启动数据库服务。

### 数据库初始化

首次启动时，系统会自动创建数据库文件 `medical.db` 并执行初始化脚本。数据库配置位于 [backend/config/database.go](../../../backend/config/database.go)。

初始化内容包括：
- 用户表（含默认管理员账户）
- 图片表
- 页面配置表

### 默认登录信息

- **用户名**: `admin`
- **密码**: `admin123`

> 注意：生产环境请修改默认密码。

## 项目导入到 IDE

### GoLand 导入（推荐）

1. 打开 GoLand
2. 选择 "File" -> "Open..."
3. 浏览到项目根目录并选择
4. IDE 会自动识别 Go Modules 配置
5. 等待索引完成后即可开始开发

### VS Code 导入

1. 安装 Go 扩展
2. 打开项目文件夹
3. 执行 `Go: Install/Update Tools` 安装必要工具
4. 配置 `settings.json` 中的 Go 路径

### 验证项目结构

导入后应看到以下主要目录：
- `backend/` - 后端代码（config/controllers/models/routes/services）
- `frontend/` - 前端资源（css/js/components）
- `admin/` - 后台管理界面
- `uploads/` - 上传文件存储

## 构建和运行项目

### 构建项目

在项目根目录下执行：

```bash
go build -o cms-server main.go
```

这将生成可执行文件 `cms-server`。

### 运行应用程序

有三种方式启动应用：

#### 方式一：直接运行 Go 主类

```bash
go run main.go
```

#### 方式二：运行编译后的可执行文件

```bash
./cms-server
```

#### 方式三：在 IDE 中运行

在 GoLand 或 VS Code 中找到 `main.go` 文件，点击运行按钮。

### 验证应用启动

应用启动后，您应该能看到类似以下的日志输出：

```
Server starting on :8080
```

这表示服务已在 `http://localhost:8080` 成功启动。

## API 调用示例

让我们通过一个简单的 API 调用来验证环境配置是否正确。

### 用户登录

```bash
curl -X POST "http://localhost:8080/api/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

预期响应：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user": {
      "id": 1,
      "username": "admin",
      "role": "admin"
    }
  }
}
```

### 获取页面配置

```bash
curl -X GET "http://localhost:8080/api/public/config" \
  -H "accept: application/json"
```

### 获取图片列表（需要认证）

```bash
curl -X GET "http://localhost:8080/api/admin/images" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 上传新图片

```bash
curl -X POST "http://localhost:8080/api/admin/images" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "image=@/path/to/image.jpg" \
  -F "category=banner" \
  -F "description=图片描述"
```

## 故障排除

### 常见问题及解决方案

#### 1. 端口冲突

如果 8080 端口被占用，可以在启动前设置环境变量修改端口：

```bash
export PORT=8081
go run main.go
```

#### 2. 数据库连接失败

检查数据库文件是否正确生成：

```bash
ls -la medical.db
```

如果文件不存在，删除后重新启动应用会自动创建。

#### 3. 依赖下载失败

清理模块缓存并重新下载：

```bash
go clean -modcache
go mod download
```

#### 4. 构建失败

确保 Go 版本符合要求：

```bash
go version
# 应显示 go version go1.25.0 或更高
```

#### 5. JWT 认证失败

检查 token 是否正确传递：

```bash
# 确保请求头包含有效的 JWT token
curl -H "Authorization: Bearer YOUR_TOKEN" ...
```

#### 6. 图片上传失败

检查 `uploads/` 目录是否有写权限：

```bash
chmod 755 uploads/
```
