# 产品与用户价值

## 当前产品定位

本仓库是一个**医疗设备官网内容管理系统（CMS）**，基于 Go + Gin + SQLite 构建，为医疗设备企业提供一站式官网内容管理解决方案。

- **交付对象**：医疗设备公司的市场/运营团队
- **核心能力**：无需修改代码即可管理官网的 Banner、产品展示、关于我们等内容模块
- **技术特点**：内嵌 SQLite 数据库，零配置部署；JWT 认证保障后台安全；支持中英文多语言内容

项目完整说明见 [README.md](../../../README.md)。

## 目标用户与场景

### 主要用户

| 用户角色 | 使用场景 | 关键任务 |
|----------|----------|----------|
| 内容运营人员 | 更新官网展示内容 | 上传产品图片、修改 Banner 文案、调整页面配置 |
| 市场管理员 | 管理多语言内容 | 维护中英文产品描述、配置国际化展示 |
| 系统维护人员 | 日常运维 | 用户权限管理、图片分类管理、数据备份 |

### 核心使用场景

1. **产品图片管理**：运营人员可通过后台上传、分类、删除产品图片，图片自动同步至官网展示
2. **页面配置管理**：无需开发人员介入，直接修改 Banner 标题、副标题、各模块开关状态
3. **多语言内容维护**：支持中英文双语内容录入，前台根据语言设置动态展示对应内容

后台管理入口位于 `/admin`，默认登录凭据为 `admin/admin123`（生产环境应修改）。

## 核心价值

### 已确认的价值主张

1. **零数据库配置**：SQLite 内嵌部署，无需单独安装数据库服务，降低运维成本
2. **即改即生效**：页面配置修改后刷新官网即可看到更新，无需重新部署
3. **多语言支持**：内容模型内置中英文字段（`zhTitle`/`enTitle`、`zhDescription`/`enDescription`），支持国际化展示
4. **前后端分离架构**：后端提供 RESTful API，前端通过 CMS Service 动态加载配置，便于扩展

技术实现细节可参考：
- [后端控制器](../../../backend/controllers/)：内容管理、图片管理、用户管理等核心逻辑
- [前端组件](../../../frontend/js/)：响应式官网页面组件，支持动态内容渲染

### 差异化特点

- 专为医疗设备行业设计，页面模块（Banner、产品展示、工厂介绍、统计数据等）贴合行业展示需求
- 轻量级部署，单二进制文件 + 数据库文件即可运行

## 非目标与边界

### 当前不覆盖的能力

1. **多租户支持**：系统为单租户设计，不支持多企业/多站点隔离
2. **复杂工作流**：内容发布无审批流程，修改后直接生效
3. **高级媒体处理**：图片仅支持基础上传/存储，无压缩、裁剪、水印等处理
4. **第三方集成**：未集成 CDN、对象存储、消息队列等外部服务
5. **移动端 App**：仅提供响应式 Web 官网，无独立移动应用

### 使用限制

- 数据库采用 SQLite，适用于中小型网站；如访问量较大需评估性能瓶颈
- 认证采用基础 JWT 方案，无 OAuth、SSO 等企业级集成
