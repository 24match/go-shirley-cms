# 安全说明

## 当前安全边界

本项目为医疗设备官网内容管理系统，涉及以下安全边界：

### 敏感数据
- **用户凭证**：管理员账号密码存储于 SQLite 数据库，使用 bcrypt 加密
- **JWT 密钥**：用于 Token 签名的密钥配置于代码中
- **上传文件**：图片文件存储于 `uploads/` 目录，可通过公开路径访问

### 外部服务
- 无外部服务依赖，数据库采用内嵌 SQLite

### 高风险操作边界
- **管理接口**：`/api/admin/*` 路径下的所有操作（图片上传/删除、配置修改、内容管理）
- **文件上传**：支持多图片上传，存储至服务器文件系统
- **数据库写入**：页面配置、模块配置、多语言文本的增删改操作

### API 权限划分

| 接口前缀 | 认证要求 | 说明 |
|----------|----------|------|
| `/api/login` | 无 | 用户登录获取 Token |
| `/api/public/*` | 无 | 公开数据读取（配置、图片、内容） |
| `/api/admin/*` | 需要 JWT | 所有管理操作 |

## 已有保护措施

### 认证机制
- 采用 JWT Token 认证，Token 有效期 24 小时
- 管理接口通过 [AuthMiddleware](../../../backend/middleware/auth.go) 统一拦截未授权请求
- 支持 `Bearer` 前缀的 Authorization 头解析

### 密码安全
- 用户密码使用 `bcrypt` 算法加密存储（cost factor: default）
- 登录时通过 `bcrypt.CompareHashAndPassword` 进行密码验证
- 来源：[database.go](../../../backend/config/database.go)（密码哈希生成）、[user_service.go](../../../backend/services/user_service.go)（密码验证）

### 请求校验
- 登录接口对 username/password 字段进行 `binding:"required"` 校验
- 所有管理接口在 Token 无效时返回 401 Unauthorized

### CORS 配置
- 启用跨域支持，允许所有来源（`Access-Control-Allow-Origin: *`）
- 允许方法：GET, POST, PUT, DELETE, OPTIONS
- 允许头：Content-Type, Authorization

### 错误处理
- 统一错误处理中间件捕获 panic，避免敏感信息泄露
- 来源：[ErrorHandler](../../../backend/middleware/error_handler.go)

## 风险与注意事项

### 已知安全风险

#### 1. JWT 密钥硬编码
- **风险描述**：JWT 签名密钥直接硬编码于 [config.go](../../../backend/config/config.go) 中
- **当前值**：`medical-device-cms-secret-key-2024`（已脱敏显示）
- **建议**：生产环境应通过环境变量注入，避免密钥随代码泄露

#### 2. 默认凭证硬编码
- **风险描述**：默认管理员密码硬编码于 [database.go](../../../backend/config/database.go) 的 `initDefaultUser()` 函数
- **默认账号**：`admin` / `***`（已脱敏）
- **建议**：首次部署后应立即修改默认密码，或通过环境变量配置初始凭证

#### 3. 文件上传缺少校验
- **风险描述**：[image_controller.go](../../../backend/controllers/image_controller.go) 中的图片上传功能未进行：
  - 文件类型校验（仅依赖前端传入的文件名）
  - 文件大小限制
  - 文件内容安全检查（Magic Number 验证）
- **建议**：
  - 添加白名单校验（仅允许 jpg/png/gif 等图片格式）
  - 限制单文件大小（如 5MB）
  - 使用文件内容检测而非仅依赖扩展名

#### 4. 静态文件目录遍历风险
- **风险描述**：`/uploads` 和 `/frontend` 目录通过 `r.Static()` 直接暴露
- **建议**：确保 uploads 目录中不存储敏感文件，必要时添加访问控制

#### 5. CORS 配置过于宽松
- **风险描述**：当前允许所有来源访问 API（`Access-Control-Allow-Origin: *`）
- **建议**：生产环境应限制为具体的域名白名单

### 安全待办事项

| 优先级 | 事项 | 状态 |
|--------|------|------|
| 高 | JWT 密钥迁移至环境变量 | 待实施 |
| 高 | 文件上传类型/大小校验 | 待实施 |
| 中 | CORS 域名白名单配置 | 待实施 |
| 中 | 默认密码强制修改机制 | 待实施 |
| 低 | 添加请求频率限制 | 后续可补充 |
